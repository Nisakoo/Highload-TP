# Рассчетно-пояснительная записка для Курсовой работы по предмету "Разработка высоконагруженных приложений"

### 1. Тема и целевая аудитория

**Тип:** ИИ-сервис (аналог Алиса AI)

**Целевая аудитория:** 4,5 млн DAU; 19,0 млн WAU; 30,0 млн MAU (согласно финансовому отчету Q4 2025, но в Q2 2026 WAU 33,2 млн). Продукт ориентирован на российский рынок

**Основной функционал MVP:**
1. Регистрация/авторизация пользователя
2. Диалоги с ИИ^1^
3. История диалогов с поиском
4. Голосовой ввод, голосовые ответы
5. Загрузка файлов

**Ключевые продуктовые решения:**
1. Ответ передается пользователю потоково
2. Для длинных диалогов используется только релевантная часть контекста
